# TypeSpeedApp

Welcome to **TypeSpeedApp** – a comprehensive typing speed trainer for Windows and other platforms!

---

## ✨ Features

### Test Modes
- **Complete Text**: Type entire sentences to completion
- **Timed Tests**: 30 seconds, 1 minute, 2 minutes, 5 minutes

### Practice Modes  
- **Normal Text**: Regular sentences for general practice
- **Numbers**: Focus on numeric typing and calculations
- **Punctuation**: Master special characters and punctuation
- **Programming**: Code snippets and programming syntax
- **Famous Quotes**: Inspirational quotes and sayings
- **Custom**: Your own custom sentences

### Enhanced Interface
- Real-time WPM, accuracy, and error tracking
- Color-coded results and feedback
- Progress bars and visual indicators
- Pause/resume functionality
- Integrated high score tracking
- Modern dark theme interface

### Customization
- Adjustable font size and family
- User preferences and settings
- Optional error highlighting
- Real-time statistics toggle
- Export functionality for results

### Content Quality
- 20+ sentences per difficulty level
- Technical and programming content
- Specialized practice content
- Expandable with custom sentences

## 🖥️ Installation

### **Quick Start (Windows)**

1. Download the release package
2. Extract to any folder
3. Double-click `TypeSpeedApp.bat` to launch
4. No Java installation needed if using the launcher!

### **Manual Installation**

1. Ensure Java 17 or later is installed
2. Download `TypeSpeedApp.jar`
3. Run: `java -jar TypeSpeedApp.jar`
