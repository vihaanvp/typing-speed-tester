# TypeSpeedApp Installation and Usage Instructions

## Windows Installation

### Option 1: Java Required
1. Ensure Java 17 or later is installed on your system
2. Download `TypeSpeedApp.jar` from the releases
3. Double-click the JAR file or run: `java -jar TypeSpeedApp.jar`

### Option 2: Standalone (Recommended)
1. Download both `TypeSpeedApp.jar` and `TypeSpeedApp.bat`
2. Place both files in the same folder
3. Double-click `TypeSpeedApp.bat` to run

The `.bat` file will automatically find Java on your system and launch the application.

## Features

### Test Modes
- **Complete Text**: Type the entire sentence to completion
- **30 Seconds**: Type as much as possible in 30 seconds
- **1 Minute**: Type as much as possible in 1 minute  
- **2 Minutes**: Type as much as possible in 2 minutes
- **5 Minutes**: Type as much as possible in 5 minutes

### Difficulty Levels
- **Easy**: Simple sentences with common words
- **Medium**: More complex sentences with varied vocabulary
- **Hard**: Technical and challenging sentences

### Statistics Tracked
- Words Per Minute (WPM)
- Characters Per Minute (CPM)
- Accuracy percentage
- Error count
- Progress tracking
- High scores for each difficulty level

### Custom Sentences
Add your own practice sentences by:
1. Go to Options → Add Custom Sentences
2. Create text files in the opened folder:
   - `easy_sentences.txt`
   - `medium_sentences.txt` 
   - `hard_sentences.txt`
3. Add one sentence per line
4. Restart the application

## Offline Operation
This application works completely offline - no internet connection required!

All resources are bundled within the JAR file, and user data is stored locally.
